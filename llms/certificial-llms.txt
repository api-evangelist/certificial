# Certificial

> Certificial operates the Smart COI Network, a real-time certificate of insurance (COI)
> tracking, issuance and compliance platform for requestors, insureds, and insurance agents
> and brokers. It replaces the static PDF certificate with a continuously monitored Smart COI
> that reflects policy-level changes as they happen. Certificial markets two APIs to software
> platforms — an Insurance Tracking API and a COI Issuance API — but publishes no public API
> reference, OpenAPI definition, or developer portal; API access is arranged through a sales
> conversation.

## APIs

- [Certificial Insurance Tracking API](https://www.certificial.com/insurance-tracking-api): Bi-directional API for technology platforms to request coverage for their customers' suppliers and receive real-time, source-verified policy data, PDF certificates and endorsements, compliance status against requirements, exceptions and overrides, and coverage-change history. No public reference or spec.
- [Certificial COI Issuance API](https://www.certificial.com/coi-issuance-api): API for InsurTech platforms and agency-management systems to automate COI distribution — generating ACORD 24, 25, 27, 28 and 101 forms and automatically reissuing certificates when the underlying policy or schedule changes. No public reference or spec.

## Access

- API root: https://my.certificial.com/api/ — live, credential-gated. Returns HTTP 401 `{"detail":"Authentication credentials were not provided."}` with a `WWW-Authenticate: Token` challenge (Django REST Framework token authentication).
- [Sign in / register](https://my.certificial.com/login)
- API access is arranged through a call, not self-serve: the API product pages link to a Calendly reseller-program booking rather than to documentation.
